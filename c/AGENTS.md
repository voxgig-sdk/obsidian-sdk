# Obsidian C — Agent Guide

The C client for the Obsidian API. This directory is **generated** — do not edit it by hand; change the model/template/component in `.sdk/` and regenerate. See the [project guide](../AGENTS.md) for the full workflow and the aontu model language.

> Paths below (`.sdk/…`) are relative to the **project root** — one level up
> from this `c/` directory.

## Regenerate this target

```bash
cd ../.sdk
npm run build        # only if you changed a component
npm run generate     # refreshes this c/ directory
```

Then build and test the generated output:

```bash
# in this target directory (c/):
make build
make test
```


## What generates this target

| Source | Path | Edit when… |
| --- | --- | --- |
| Target definition | `.sdk/model/target/c.aon` | deps, module, extension, phases change |
| Templates | `.sdk/tm/c/` | the file is the **same for every API** (runtime, transport, base classes) — copied verbatim with placeholder substitution |
| Components | `.sdk/src/cmp/c/` | the file's shape **depends on the API** (entities, constructor, README, tests) — TypeScript that walks the model |

Decision rule: *same for every API → template; depends on the API →
component.* After editing a component run `npm run build` before
`npm run generate`; template-only edits just need `npm run generate`.
