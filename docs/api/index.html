API overview

The Obsidian Local REST API with MCP plugin gives you two ways to interact with your Obsidian vault programmatically:

  • https://{host}:{port}: HTTPS (Secure Mode)
  • http://{host}:{port}: HTTP (Insecure Mode)

This documentation is generated from the OpenAPI specification held in the SDK repository.
